# ADR-0001: Восемь независимых TWYLT-обёрток

Статус: принято. Дата: 2026-10-01.

1. Один инструмент на операцию; понятные агенту отдельные схемы, без универсального
   shell/args. TWYLT 1.0.0 отвечает за транспорт, discovery и строгий контракт.
2. Git CLI вместо GitPython: штатные credentials, протоколы и поведение Git,
   минимум Python-зависимостей. Git требуется установить отдельно.
3. Генерировать самодостаточные tool.py из общего исходника: перенос исходного
   кода в ToolHub не должен зависеть от соседнего модуля. Генератор детерминированный.
4. put означает запись одного текстового файла, не add и не upload на сервер.
   overwrite явно разрешает замену; .git, traversal и symlink не поддерживаются.
5. pull fast-forward only, push без force, commit только индекс. Разрешение
   конфликтов, управление ветками и разрушительные операции вне версии 0.1.
6. Ожидаемые отказы Git — Result с ok=false и оригинальным returncode.
   Нарушения входного контракта и исключения — стандартные ошибки TWYLT.
   Это сохраняет диагностический вывод Git без подмены кодом бизнес-исключения.
7. Тесты на настоящих временных локальных репозиториях сохраняются и накапливаются.
8. Пути в add/diff literal, все аргументы без shell, закрытый stdin для Git.
   Обёртки не заменяют sandbox/разрешения агента и не меняют TWYLT transport.
