# ADR-0002: Status и log

Статус: принято. Дата: 2026-10-01.

1. Два самостоятельных инструмента, генерация и доставка по ADR-0001.
2. Сохраняем Result и текст stdout: минимум нового контракта. Status использует
   porcelain v1 с branch, log — fuller с ISO-датами либо full hash + subject.
   Структурированный разбор и дополнительная агрегация вне 0.2.0.
3. Log ограничен 20 коммитами по умолчанию, до 1000 по запросу. skip для пагинации.
   Revision предварительно разрешается в hash, произвольные опции не принимаются.
4. Status работает и без первого коммита. Log без HEAD возвращает отказ Git,
   сохраняя согласованность с diff и общими правилами ошибок.
5. Оба инструмента читают состояние. Status передаёт --no-optional-locks,
   чтобы не выполнять необязательное обновление индекса.
6. Старые регрессии сохраняются; новые тесты проверяют статус индекса/рабочей
   копии, фильтры, лимиты, пагинацию, неизвестные ревизии и discovery.
